# HAP Pay Demo

A clearly labelled learning-only payment UI demo.

## Run on Android
1. Download and extract `hap-pay-demo.zip`.
2. Open `index.html` in Chrome, or use a code editor with a local preview.
3. Enter a fictional 10-digit mobile number and a demo amount.
4. Tap the demo button. It never transfers money.

## Upload to GitHub
1. Open your `Fake-phonepe-demo` repository.
2. Tap **Add file** -> **Upload files** (or the empty-repository upload link).
3. Upload `index.html`, `style.css`, `app.js`, and `README.md` from the extracted folder.
4. Tap **Commit changes**.

## Safety
No UPI integration, bank connection, QR payments, payment confirmation, UTR, or real transaction capability.
